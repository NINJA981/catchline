The catch, next to the claim.

Catchline matches every *, † and ¹ on a page to its footnote and lists the fees and conditions right next to the claim. Free and open source. Nothing leaves your browser.

Try it in your browser, no install Install the extension from source

The extension needs desktop Chrome, Edge or Firefox. The web app runs in any browser, phones included.

Every page, checked before you read it.

Catchline scans each page as it loads. When it finds fine print attached to a price, a rate or a promise, the toolbar shows how many catches it found and what they add up to.

Only commerce catches are counted: money, time, rate, requirement, exclusion or renewal terms. A plain reference footnote on an article never raises the number.

How it works, in your browser.

  1. 1

    Find

    Scans text for *, †, ‡, §, ¶ and superscript numbers, and skips prices like $4999, math and code.

  2. 2

    Match

    Follows linked footnotes first, then looks bottom-up through the page’s legal and fine-print sections for the same symbol.

  3. 3

    Extract

    Pulls out money, time, rates, requirements, exclusions and renewals with fixed rules. No AI and no account.

  4. 4

    Draw

    Draws the line and the card in its own layer, so the page itself never moves.

Accuracy: not yet measured

The corpus of saved offer pages that CI scores has not been captured, so there is no precision or recall number to show. Until there is, this page does not make one up. The only fixtures today are hand-written specimens.

You do not have to take any of this on trust. The web app runs the same engine on whatever you paste.

Nothing leaves your browser. Check it yourself.

  • No network requests

    The extension has no analytics, no telemetry, no font CDN and no update ping. The repository has a script that fails if the build contains a network call, and an end-to-end test that loads the built extension and asserts zero requests.

  • What it keeps

    Your settings, in extension storage. Per-tab counts and term strings, which are gone when the tab closes. No URLs and no page text.

  • What it can read

    Pages, so it can find the fine print on them. Its permissions are storage, scripting, the active tab and access to all sites. Nothing else.

Try the web app
Terminal 
pnpm install
pnpm build            # Chrome: .output/chrome-mv3
pnpm build:firefox    # Firefox: .output/firefox-mv3
  1. Chrome or Edge. Open chrome://extensions, turn on Developer mode, choose Load unpacked, and pick .output/chrome-mv3.
  2. Firefox. Open about:debugging, choose This Firefox, then Load Temporary Add-on, and pick .output/firefox-mv3/manifest.json. Allow Catchline to read pages when asked.
  3. Use it. Click any * on an offer page, or press Alt Shift C to see every catch.

Open source under the MIT license.

The engine is plain TypeScript in one folder. The extension imports it, and so does the web app on this site, so what you try here is what the extension runs.

  • Fix a wrong match

    Save the page that fooled it as a fixture with the pair you expected. The corpus is the only thing allowed to move the rules.

  • Teach it a vocabulary

    Extractor rules are ordered regular expressions per page family: carrier, bank, retail, streaming, software pricing and travel.
